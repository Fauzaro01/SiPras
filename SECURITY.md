# Security Policy

Komunitas keamanan itu penting. Kami menghargai upaya Anda untuk melaporkan kerentanan secara bertanggung jawab.

## Versi yang Mendukung

| Versi    | Didukung |
| -------- | -------- |
| main     | ✅        |
| < main   | ❌        |

## Melaporkan Kerentanan

**JANGAN membuka issue publik** untuk laporan kerentanan keamanan.

Sebagai gantinya, kirim laporan Anda secara **pribadi** melalui [Security Advisories](https://github.com/fauzaro01/SiPras/security/advisories/new) di GitHub.

Harap sertakan sebanyak mungkin informasi berikut untuk membantu kami mereproduksi:

- Jenis kerentanan (mis. XSS, SQL injection, IDOR)
- URL/lokasi yang terkena (endpoint, controller, method)
- Langkah reproduksi
- Dampak potensial
- (Jika ada) usulan perbaikan

## Proses

Kami akan mengakui laporan Anda dalam **48 jam**, memberi perkiraan waktu perbaikan, dan memberi dukungan saat kami meneliti serta memperbaiki masalah tersebut. Informasi yang Anda berikan tidak akan dibagikan kepada pihak ketiga tanpa izin tertulis Anda.

Terima kasih telah membantu menjaga SiPras tetap aman dan terpercaya.
